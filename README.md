# Мои карты — PWA-кошелёк для дисконтных карт

Минималистичное PWA-приложение в стиле Apple Wallet для хранения дисконтных
и бонусных карт. Работает полностью локально (в браузере), без бэкенда —
всё, что нужно для запуска, это статический хостинг, например GitHub Pages.

## Возможности

- Добавление, редактирование и удаление карт
- Список карт — каждая карта видна целиком, тап переворачивает её (3D-flip)
  и показывает QR-код или штрих-код — что генерировать, указывается при
  создании карты
- Кнопка-лупа на каждой карточке — открывает код на весь экран, минуя
  переворот, на сплошном белом фоне для максимального контраста при
  сканировании на кассе
- Поддержка форматов штрих-кодов: CODE128, EAN-13, EAN-8, UPC-A, CODE39,
  ITF-14, Codabar
- Своя фотография карты (по желанию) — если не загружена, генерируется
  красивая цветная карточка с выбранным акцентным цветом
- Данные хранятся только на устройстве (`localStorage`), офлайн-доступ через
  Service Worker, устанавливается на домашний экран iPhone как обычное
  приложение
- Тёмная и светлая темы — подстраивается под системную тему iOS
- Работает и в портретной, и в альбомной ориентации

### Про яркость экрана

Ни один браузер (включая Safari на iOS) не даёт веб-страницам доступа к
регулировке реальной яркости экрана — это намеренное ограничение приватности
на уровне ОС, и обойти его нельзя ни на сайте, ни в PWA. Вместо этого при
показе кода (через переворот карты или лупу) экран отображает код на
сплошном белом фоне на весь экран — это максимально повышает контраст и
воспринимаемую яркость и является стандартным приёмом всех веб-кошельков.
Если нужна именно системная яркость — это решается только нативным
приложением через специальный API, недоступный из браузера.

### Про сохранность данных и резервные копии

Карты хранятся в `localStorage` — то есть только в этом браузере на этом
устройстве, без сервера. Это удобно (не нужен бэкенд, ничего не течёт наружу),
но есть риск потери данных:

- ручная очистка **Настройки → Safari → Дополнительно → Данные веб-сайтов**;
- удаление иконки приложения с домашнего экрана и переустановка;
- сброс/восстановление устройства;
- в теории — вытеснение данных системой при критической нехватке места.

Чтобы защититься, в приложении есть кнопка **резервной копии** (иконка со
стрелкой рядом с «+» в шапке):

- **Экспортировать резервную копию** — сохраняет все карты (включая фото) в
  один `.json`-файл через системный диалог «Сохранить» / в приложение
  «Файлы».
- **Импортировать из файла** — восстанавливает карты из такого файла (можно
  на любом устройстве и в любой момент, добавляются к уже существующим,
  не затирая их).

Рекомендация: делайте экспорт после добавления важных карт и храните файл
в iCloud Drive / Файлах — это единственная надёжная страховка при полностью
локальном (без сервера) приложении.

## Структура проекта

Все файлы лежат в корне репозитория (без подпапок) — так их проще
загрузить через веб-интерфейс GitHub:

```
wallet-pwa/
├── index.html          # разметка приложения
├── manifest.json        # манифест PWA (иконки, имя, цвета)
├── sw.js                 # Service Worker (офлайн-кеш)
├── styles.css             # все стили
├── db.js                   # хранение карт в localStorage
├── codegen.js               # генерация QR / штрих-кодов
├── app.js                    # основная логика интерфейса
├── qrcode.min.js               # генератор QR-кодов (qrcode-generator, MIT)
├── jsbarcode.min.js             # генератор штрих-кодов (JsBarcode, MIT)
├── icon-*.png, apple-touch-icon.png, favicon.ico   # иконки всех размеров
└── icon-source.svg, icon-maskable.svg               # исходники иконки
```

## Деплой на GitHub Pages

1. Создайте на GitHub пустой репозиторий с именем **`wallet-pwa`**
   (без README/лицензии, чтобы не было конфликтов).
2. Загрузите в него все файлы из этой папки, сохранив структуру каталогов:

   ```bash
   cd wallet-pwa
   git init
   git add .
   git commit -m "Initial commit: wallet PWA"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/wallet-pwa.git
   git push -u origin main
   ```

3. В репозитории на GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/(root)**
5. Сохраните. Через 1–2 минуты приложение будет доступно по адресу:

   ```
   https://<ваш-логин>.github.io/wallet-pwa/
   ```

Все пути в проекте относительные (`./`, `icons/...` и т.д.), поэтому
приложение корректно работает как в подпапке `/wallet-pwa/` (обычный проект
на GitHub Pages), так и в корне домена, если вы используете кастомный домен.

## Установка на iPhone (iOS 17 / Safari)

1. Откройте ссылку `https://<ваш-логин>.github.io/wallet-pwa/` в **Safari**
   (обязательно Safari, не Chrome — только он умеет ставить PWA на iOS).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран «Домой»»**.
4. Приложение появится на домашнем экране с иконкой и будет открываться в
   полноэкранном режиме, без адресной строки Safari.

## Локальная проверка перед деплоем

Service Worker и `fetch`-запросы манифеста не работают при открытии
`index.html` напрямую через `file://`. Поднимите локальный сервер, например:

```bash
cd wallet-pwa
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Важно про данные

Карты хранятся в `localStorage` браузера **того устройства**, на котором вы
их добавили. Синхронизации между устройствами нет — это простое локальное
хранилище без сервера. Если вы очистите данные сайта в Safari или
переустановите приложение с нуля, карты будут потеряны, поэтому не
удаляйте вкладку/данные сайта, если карты важны.

## Смена иконки или акцентного цвета

- Исходник иконки — `icon-source.svg` (полноразмерная версия) и
  `icon-maskable.svg` (версия с отступами под «maskable» безопасную
  зону). Отредактируйте SVG и перегенерируйте PNG любым конвертером
  (например, `cairosvg` или https://realfavicongenerator.net).
- Акцентный цвет интерфейса — переменная `--accent` в начале файла
  `css/styles.css`, а также поле `theme_color` в `manifest.json` и
  `<meta name="theme-color">` в `index.html`.
